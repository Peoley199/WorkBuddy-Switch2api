## 复现实验的通用手法

排查上游问题时，**用不存在的模型名当探针**，零额度消耗就能把两类失败分开：

| 上游返回 | 含义 |
|---|---|
| `11102 model [...] service info not found` | 请求**通过了**渠道校验，只是模型不存在 |
| `11128` | 被**渠道校验**拦下（再看 `msg` 区分负载变体 / 客户端身份变体） |
| `11101` | **参数解析失败**（发生在渠道校验**之前**，别误判成模型问题） |

用真模型去试会实打实消耗额度，没必要。
